# Мой турник — трекер домашних тренировок

Четыре недели домашних тренировок (с 23.11.2026 по 20.12.2026): турник, отжимания, зарядка и восстановление.

Открыть приложение: https://murslend.github.io/forma-83/turnik/

## Как добавить на экран iPhone

Открой страницу в Safari. Нажми «Поделиться» → «На экран Домой» → «Добавить».

## Приватность

Отметки и показатели сохраняются локально в памяти браузера этого устройства. В репозиторий и на GitHub они не отправляются. Для переноса используй «Настройки» → «Сохранить», сохрани .json в «Файлы», затем используй «Восстановить».

На новом устройстве записи не появляются автоматически.
